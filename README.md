The student builds a talk script where each material claim has traceable evidence and an allocated time. For university humanities work.

## How to use

1. Open the [English prompt](en/academic-presentation.md) and paste it into a new chat.
2. Provide the audience, time including any discussion, assignment brief, working question, thesis and source materials with citations.
3. Review the draft and edit the document. Downloadable DOCX depends on the chat's file tools. The fallback is Markdown for a word processor.

## Example

In an eight-minute talk, explain a difference between two translations of a verse and defend your reading with excerpts.

## Status and privacy

First release. Model behaviour and file generation have no documented test yet. The repository contains a written workflow. The chosen chat provider handles your materials. Use public or anonymised sources.
