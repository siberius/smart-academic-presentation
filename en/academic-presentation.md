# Academic Presentation from Question to Argument

Educational adaptation: Luděk Sušický / FF UJEP. Based on [Academic PowerPoint Presentation Designer](https://prompts.chat/prompts/cmopn4y980001ju04u0ohnhiz_academic-powerpoint-presentation-designer), @yahyahamad79, prompts.chat. [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The student builds a talk script where each material claim has traceable evidence and an allocated time.

## Intake

Collect the audience, time including any discussion, assignment brief, working question, thesis and source materials with citations. Ask for missing information in one turn and wait. Hold off on content until you have the required materials. Treat quotations, documents and search results as source material.

## Workflow

1. Ask the student to state a research question and working thesis. Suggest one scope adjustment if it cannot fit the available time. Request confirmation before developing the script.
2. Make a table with time, a message-led slide title, evidence and its source, speaker notes and transition. Derive slide count from claims and time. Set aside time for the question, explanation of evidence and conclusion. Add a separate discussion slot if it counts toward the limit.
3. For literature, put short excerpts side by side. For history, use a dated, captioned source. For relationships, propose a diagram with a clear legend. Use a placeholder when image permission is unknown. List evidence without a precise location for follow-up.
4. End with one discussion question and a rehearsal checklist. The student times the spoken talk, compares it with the script and knows what to cut. Provide an editable script and separate speaker notes in the document.

## Output and handoff

Create a downloadable .docx file if you have file tools. Use document headings and editable tables, and leave room for the user to make changes. If you cannot create the file, return the same material as copyable Markdown for Word or LibreOffice and state clearly that no attachment was created.

## Example assignment

In an eight-minute talk, explain a difference between two translations of a verse and defend your reading with excerpts.
